# PatchFlow 效率消融

## 结果

| 指标 | Baseline | Full | 变化 |
| --- | ---: | ---: | ---: |
| 成功率（15 项） | 93.3%（14/15） | 100%（15/15） | +6.7 pp |
| 平均 Token（双方成功的 14 项） | 41,635 | 34,406 | -17.4% |
| 平均 Agent Steps（双方成功的 14 项） | 5.14 | 4.64 | -9.7% |

## 口径

- 任务：`v2_suite` 前 15 项
- 模型：`deepseek-ai/DeepSeek-V4-Flash`
- 上限：40 Steps、80,000 Tokens、300 秒
- Baseline 关闭失败分析、混合检索、编辑规划和自审；Full 全部开启
- 效率指标仅统计双方均成功的任务；Full 取每项三次运行的中位数

若改用 Full 三次运行的均值，Token 降幅为 5.3%。因此 17.4% 应表述为配对中位运行结果。
